# Curriculum Learning (Step 7) — Implemented

**Status:** built and tested. The framework orchestrates 7-stage
training over a schema_v2 corpus with stage-specific filtering,
domain-stratified sampling, rehearsal of earlier stages, and
gate-based stage transitions.

## Module layout

```
src/irab_tashkeel/curriculum/
  config.py     — StageConfig + DEFAULT_STAGES (7 stages)
  sampler.py    — StratifiedSampler + StagePool
  gates.py      — GateDecision + evaluate_gate()
  scheduler.py  — CurriculumScheduler (top-level orchestration)
  __init__.py   — public API
```

## Default 7-stage schedule

| stage | name | difficulty | filters | rehearsal | gate metric | threshold |
|---:|---|---|---|---:|---|---:|
| 1 | morphology_foundation | 1 | tokens-only graph, MSA news | 0% | morph_macro_f1 | 0.90 |
| 2 | local_syntax | 1-2 | sp ≤ 1, dep edges | 15% | role_f1 | 0.40 |
| 3 | simple_constructions | 1-3 | sp ≤ 1, drop ambiguous | 20% | construction_f1_macro | 0.60 |
| 4 | nested_syntax | 1-4 | sp ≤ 2, allow overlap | 20% | fully | 0.25 |
| 5 | semantic_interactions | 1-5 | sp ≥ 2 | 25% | fully | 0.30 |
| 6 | discourse_sensitive | 1-6 | sp ≥ 2 + discourse refs | 30% | fully | 0.30 |
| 7 | quranic_classical | 1-7 | full edges | 35% | quranic_fully | 0.20 |

Per-stage `target_steps` and `max_steps` are set conservatively;
the gate logic falls back to `TIMEOUT_ADVANCE` when `max_steps`
is reached without meeting the threshold.

## Usage from a trainer

```python
from irab_tashkeel.curriculum import CurriculumScheduler, GateDecision
from irab_tashkeel.data_v2.schema_v2 import read_jsonl

# Load corpus
sentences = list(read_jsonl("data_v2/annotated/distill_v2/all.jsonl"))
sentences += list(read_jsonl("data_v2/annotated/masaq_quranic/all.jsonl"))
# … etc

sched = CurriculumScheduler.from_corpus(sentences)

while not sched.is_done():
    sampler = sched.make_sampler(batch_size=32)
    for batch in sampler:
        loss = trainer.train_step(batch)
        if step % eval_interval == 0:
            metrics = trainer.run_eval(dev_set)
            gate = sched.advance_or_continue(metrics)
            if gate.decision in (GateDecision.ADVANCE,
                                  GateDecision.TIMEOUT_ADVANCE):
                trainer.save_checkpoint(f"stage_{sched.state.history[-1]['stage_id']}")
                break    # rebuild sampler with new stage
```

## Engineering principles

- **Deterministic.** Same seed + same corpus + same configs ⇒ same
  batch sequence. Reproducible runs.
- **Decoupled from trainer.** The scheduler doesn't know about
  models or losses. It only knows about sentences and metrics.
- **Stage configs are data.** Modify `DEFAULT_STAGES` to change
  the curriculum without touching trainer code.
- **Earlier-stage rehearsal.** Each later stage rehearses earlier
  stages' samples at increasing proportion (`rehearsal_ratio`),
  preventing catastrophic forgetting.

## Open design questions (deferred)

- Adaptive stage transitions (stay longer when the model is still
  improving fast)
- Per-task loss weighting per stage (e.g., emphasise morph head
  loss in stages 1-2, role head loss in 3-5)
- Curriculum-aware learning rate schedule
