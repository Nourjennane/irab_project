# Reproducibility & Ethics — Per-word Arabic i'rāb

This document collects everything needed to re-run the experiments in `docs/RESULTS.md`, plus the access/cost/ethics caveats that follow from using a closed-source LLM at the core of a low-resource-language system.

## Pinned versions

| Component | Version | Notes |
|---|---|---|
| Anthropic Python SDK | `0.97.0` | `pip install anthropic==0.97.0` |
| Python | `3.13.5` | `.venv` |
| Claude models | `claude-sonnet-4-5`, `claude-haiku-4-5` | inference-time only; no fine-tuning |
| Stanza | `1.11.1` | `stanza.Pipeline(lang='ar', processors='tokenize,mwt,pos,lemma,depparse')` — Arabic UD model auto-downloaded by `stanza.download('ar')` |

Gazelle Iraab.jsonl from UBC-NLP (EMNLP 2024 shared release): 30 hand-annotated MSA sentences = 134 word-level i'rāb judgments. Loader: `src/irab_tashkeel/data/gazelle.py`. License: per Gazelle release.

## Inference-time variance

Anthropic's Messages API does not expose a `seed` parameter, and Claude's sampling is server-side stochastic even at `temperature=0.0` (provider-level non-determinism due to GPU kernel ordering, batching, etc.). To estimate this variance, we re-ran Sonnet RAG (k=5, headline configuration) on Gazelle a second time and compared to the headline run; the variance section below records the result.

See `runs/baseline_eval_sonnet_repro/` for the second run and `reproducibility/variance.md` for the comparison.

| Marker FT for Mix A (Hybrid baseline) | one-shot, AraT5v2 on A100 MIG slice | $0 (compute only) | 27 min |

Spend is small because the eval set is small (n=134) and Claude inputs are short. **A practitioner with $10 of API credit and an internet connection can reproduce every number in `docs/RESULTS.md`.** This is favorable for reproducibility relative to systems that require $1k+ to retrain.

## Limitations and ethics

This system uses a **proprietary closed-source LLM (Claude Sonnet 4.5)** as its core retrieval-reasoning model. The implications follow Hovy & Spruit (2016, "The Social Impact of Natural Language Processing") and Hovy & Prabhumoye (2021, "Five Sources of Bias in NLP"):

1. **Reproducibility is conditional on Anthropic's continued model availability and API access.** When `claude-sonnet-4-5` is deprecated, exact reproduction will become impossible; the closest analog will be the contemporaneous Claude generation. We mitigate by (a) pinning the exact model ID in every script, (b) saving all predictions as JSONL in `runs/baseline_eval_*` (re-scoring works without API access), and (c) documenting prompts verbatim.
2. **Vendor lock-in.** Switching to a different vendor (OpenAI, Google) requires re-running every experiment and re-validating the prompts; the API contracts are not interchangeable.
3. **No model weights → no white-box analysis.** We cannot run gradient-based attribution, weight-level interpretability, or dataset-influence analysis. The structural-extraction metric and the perturbation/discrimination audits (T6, T7) are deliberately black-box probes designed for this constraint.
4. **Cost as a barrier to access.** The $5-7 reproduction cost is low for a Western research budget but is non-zero. For researchers without API credit, the **predictions JSONLs in `runs/` allow re-scoring and re-statistics without any API calls.**
5. **Environmental footprint.** Server-side LLM inference has a carbon cost we cannot directly measure. Approximate scale: ~30 inferences per Gazelle pass ≪ a single Stable Diffusion image; this system is small relative to typical NLP workloads.
6. **Sociolinguistic register.** All experiments use Modern Standard Arabic (MSA) news/literary sentences (Gazelle, PADT). Results do not generalize to:
   - Classical Arabic (CA) — different orthographic conventions, different syntactic frequencies (richer use of mood-shifting particles, object-fronting, etc.)
   - Dialectal Arabic (Egyptian, Levantine, Maghrebi, Gulf) — different morphology, mostly no case marking
   - Quranic recitation register — phonological and prosodic features absent here
   The MASAQ-augmented retrieval pool (T5b) introduces some Quranic exposure but this is via Quranic syntax patterns retrieved as in-context examples, not via QA on Quranic test sentences.
7. **Closed-source safety filters.** Claude's content-policy filtering may refuse certain Arabic religious or political content. We did not encounter this in the 30 Gazelle sentences; we cannot guarantee a coverage-bias-free experience on adversarial inputs.
8. **Annotator-disagreement caveat (T8).** Classical naḥw genuinely admits multiple valid analyses on ~31% of words in our test set. Single-gold scoring under-counts top systems by ≤1 pp on case and 0 pp on the joint metric, but this remains a methodology constraint future work should reduce by collecting multi-annotator gold.

## What we deliberately did NOT do

- **Open-weight baseline (e.g., AraT5v2 + RAG).** Was scoped in the directive but cut: training/loading + retrieval-prompting an open Arabic LM end-to-end is a 1-2 day project that exceeds our remaining budget. We DID fine-tune AraT5v2 for Mix A's marker overlay (Phase 2 of the hybrid), so the open-weight path is half-explored; results are reported as a documented negative (Mix A does not improve on RAG).
- **CamelParser2.0 retry.** Earlier install attempt failed at 90 minutes (kenlm wheel build, supar pickle format, BertTokenizerFast API mismatch). Per supervisor directive ("Do not retry failed tasks"), kept as future work.
- **Multi-annotator gold for inter-annotator agreement.** Only one expert review pass (Sonnet-seeded, then planned-but-descoped manual correction). Future work should report Krippendorff's α.
- **External register replication.** No CA or dialectal Arabic test set was attempted.
