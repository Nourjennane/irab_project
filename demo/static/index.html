Known failure cases — the mudaaf_ilayh family

    

      The dominant role-confusion family. Three labels share an
      identical surface signature; the model cannot reliably
      distinguish them at the current data scale. See
      docs/failure_analysis/FINDINGS.md for the full analysis.
    

    

      

        Gold
        Predicted
        Count on held-out
      

      
    

    

      Why the model gets these wrong: the second noun in a noun-noun
      sequence can be (a) a mudaaf_ilayh (idafa partner — set by
      the first noun), (b) a mafoul_bih (direct object — set by
      an upstream verb), or (c) an ism_majrur (set by a
      preposition). All three surface as the same case (jarr) with the same
      marker (kasra). Resolving them requires verb-argument knowledge,
      which is beyond what the model is trained on.
    

  







  

    
Leakage case study

    

      An earlier curriculum run reported an apparent 0.999 MASAQ fully
      accuracy. The independent eval traced the result to
      gazelle_test and masaq_quranic being silently
      present in the curriculum's training pool — the model had memorised
      the test set. The leak-free retraining produced the validated
      recovery checkpoint that ships today.
