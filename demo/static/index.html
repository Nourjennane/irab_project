The leakage discovery

An earlier curriculum run reported an apparent 0.999 MASAQ fully. Independent eval traced the result to test sources being silently in the training pool. The model had memorised the test set. The validated_recovery checkpoint is the leak-free retraining.

Three runtime assertions now refuse test sources from entering training

At module load · at pool build · at sentence eligibility — plus a provenance manifest with declared split_role per source. The bug class cannot recur silently.
